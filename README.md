Wtyczka WordPress optymalizująca wydajność strony + AI + SEO + Naprawa.

## ✨ Nowe Funkcje v2.0

### 🤖 AI Integration
- **OpenAI (ChatGPT)** - Auto-generowanie treści i optymalizacja SEO
- **Anthropic (Claude)** - Zaawansowana analiza tekstu
- **Google Gemini** - Szybkie przetwarzanie danych
- **Cohere** - Alternatywny dostawca AI

### 🔍 SEO Optimization
- Meta tagi (title, description, keywords)
- Schema.org strukturalne dane
- Open Graph & Twitter Card
- Automatic XML Sitemap

- Robots meta tags

### 🔧 Site Repair
- Czyszczenie bazy danych

- Naprawa uprawnień
- Diagnostyka zdrowia strony
- Automatyczne naprawy

### ⚡ Performance
- Minifikacja CSS/JS
- Lazy Loading obrazów
- Defer JavaScript
- Browser Cache
- Preload zasobów krytycznych

## 📥 Instalacja

### Metoda 1: FTP/File Manager

1. Pobierz repo: https://github.com/norbertsiedlecki-prog/wp-page-optimizer
2. Rozpakuj w `wp-content/plugins/`
3. Aktywuj w WordPress Admin → Wtyczki

### Metoda 2: Git

```bash
cd wp-content/plugins/
git clone https://github.com/norbertsiedlecki-prog/wp-page-optimizer.git
```

## ⚙️ Konfiguracja AI

### 1. OpenAI (ChatGPT)
- Przejdź do: https://platform.openai.com/api-keys
- Stwórz nowy API Key
- Wklej w Panel Admin → Page Optimizer → AI Integracja

### 2. Claude (Anthropic)
- Przejdź do: https://console.anthropic.com/
- Stwórz API Key
- Wklej w konfiguracji

### 3. Google Gemini
- Przejdź do: https://makersuite.google.com/app/apikey
- Stwórz nowy klucz
- Wklej w konfiguracji

### 4. Cohere
- Przejdź do: https://dashboard.cohere.ai/
- Stwórz API Key
- Wklej w konfiguracji

## 🔍 SEO Features

1. **Meta Tags**
   - Automatyczne meta description
   - Keywords dla wyszukiwarek
   - Canonical URLs

2. **Structured Data**
   - Schema.org JSON-LD
   - Organization data
   - Product/Article markup

3. **Social Media**
   - Open Graph tags
   - Twitter Card
   - Pinterest verification

4. **Sitemap**
   - XML Sitemap
   - Dostępny na: `/sitemap.xml`
   - Auto-update przy zmianach

## 🔧 Site Repair

### Dostępne naprawy:

1. **Wyczyść Bazę Danych**
   - Usuwa duplikaty postmeta
   - Usuwa sierote wpisy
   - Czyści revisions

2. **Wyczyść Cache**
   - WordPress Object Cache
   - Transients
   - Gutenberg Cache

3. **Napraw Uprawnienia**
   - Folder permissions (755)
   - File permissions (644)
   - Database permissions

4. **Usuń Sierote**
   - Orphaned postmeta
   - Orphaned termmeta
   - Broken attachments
